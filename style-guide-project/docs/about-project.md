# О проекте

Раздел «О проекте» должен кратко объяснять, что представляет собой MenshikovAI, для чего создан проект и какие основные функции он выполняет. Правила оформления раздела:

- В первом абзаце необходимо использовать полное название «Telegram-бот MenshikovAI».
- После первого упоминания допускается использовать сокращенное название «MenshikovAI» или слово «бот».
- Описание необходимо начинать с назначения проекта, а затем переходить к его основным функциям.
- Основные функции требуется оформлять маркированным списком.
- Следует использовать нейтральный технический стиль. Не допускаются рекламные формулировки, например «уникальный», «лучший», «инновационный» или «очень удобный».
- Необходимо описывать только фактически реализованные возможности проекта.
- Если упоминаются используемые технологии, необходимо называть их конкретно и без лишнего перечисления второстепенных инструментов.
- Краткое описание проекта не должно содержать подробностей установки, конфигурации или внутренней архитектуры. Эти сведения необходимо размещать в соответствующих разделах.

## Пример

«Telegram-бот MenshikovAI предназначен для интерактивного знакомства с эпохой Петра I, личностью А. Д. Меншикова и историко-культурными локациями Санкт-Петербурга».
