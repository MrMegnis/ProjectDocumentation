# Установка и запуск

Раздел «Установка и запуск» должен содержать все сведения, необходимые для подготовки окружения, установки зависимостей и запуска проекта. Правила оформления раздела:

- В начале раздела необходимо перечислить предварительные требования к окружению, например версию Python и необходимые программные средства.
- Действия пользователя должны описываться в том порядке, в котором они выполняются.
- Последовательные действия необходимо оформлять нумерованным списком.
- Команды командной строки необходимо помещать в отдельные блоки кода.
- Для команд терминала следует использовать обозначение языка bash.
- В одном блоке команд следует размещать только связанные действия.
- Перед командой необходимо кратко объяснить ее назначение, если оно не очевидно из контекста.
- После выполнения значимого действия необходимо указывать ожидаемый результат.
- Нельзя включать в документацию реальные токены, пароли, ключи API и другие секретные значения.
- Если для запуска требуется конфигурационный файл или переменная окружения, необходимо сослаться на раздел «Конфигурация».
- Если команда зависит от текущего каталога, это необходимо явно указать.
- Не следует включать в инструкцию действия, которые не требуются для стандартного запуска проекта.

## Пример последовательности

1. Установить зависимости проекта.
2. Настроить необходимые параметры конфигурации.
3. Запустить основной модуль проекта.
4. Проверить, что бот начал принимать сообщения через Telegram Bot API.
