# Тестирование

Раздел «Тестирование» должен описывать, что именно проверялось, при каких условиях проводилась проверка и какой результат был получен. Правила оформления раздела:

- Необходимо отделять процедуру проверки от ее результата.
- Для каждого теста следует указывать проверяемую функцию или сценарий.
- При необходимости необходимо указывать входные данные.
- Следует указывать ожидаемый результат.
- После выполнения проверки необходимо фиксировать фактический результат.
- Нельзя писать, что функция работает корректно, если фактическая проверка не проводилась.
- Если обнаружена ошибка, необходимо кратко описать проявление проблемы.
- Если ошибка была исправлена, следует указать, что была проведена повторная проверка.
- Для нескольких однотипных проверок допускается использовать таблицу.
- Метрики необходимо приводить только при наличии фактического расчета.
- Если показатель получен на конкретной выборке, необходимо указывать это в тексте.
- Не следует использовать оценочные формулировки вроде «отличный результат» без критерия, по которому сделана такая оценка.
- Для проверки пользовательских сценариев необходимо описывать последовательность действий и ожидаемое поведение системы.
- Для автоматизированных проверок необходимо указывать используемый инструмент или команду запуска.
- Если часть функциональности не тестировалась, это следует явно обозначить, а не считать ее автоматически проверенной.
