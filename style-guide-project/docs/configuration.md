# Конфигурация

Раздел «Конфигурация» должен описывать параметры, которые необходимо задать перед запуском проекта, их назначение и правила безопасного хранения. Правила оформления раздела:

- Для каждого параметра необходимо указывать его точное имя.
- Для каждого параметра необходимо объяснять его назначение.
- При необходимости следует указывать допустимый формат значения.
- Для обязательных и необязательных параметров необходимо явно указывать их статус.
- Если у параметра существует значение по умолчанию, его необходимо указать.
- Реальные секретные значения не должны публиковаться в документации.
- В примерах следует использовать условные значения, например `YOUR_TELEGRAM_BOT_TOKEN`.
- Необходимо указывать, где хранится параметр: в переменной окружения, конфигурационном файле или другом месте.
- При описании секретных параметров необходимо отдельно указать, что файл или значение не должно попадать в публичный репозиторий.
- Если изменение параметра влияет на поведение системы, это необходимо кратко описать.
- Параметры следует группировать по назначению, если их количество становится значительным.
- Не следует дублировать полное описание одного и того же параметра в нескольких разделах документации.
