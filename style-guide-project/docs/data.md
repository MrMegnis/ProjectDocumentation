# Данные

Раздел «Данные» должен описывать структуру используемых файлов, наборов данных и правила работы с ними. Правила оформления раздела:

- Перед примером файла необходимо объяснить его назначение.
- Необходимо указывать формат данных.
- Если используется JSON, примеры необходимо оформлять в отдельных блоках кода с обозначением языка json.
- Перед примером структуры необходимо объяснять назначение основных полей.
- Не следует публиковать большие фрагменты реальных данных, если для объяснения достаточно сокращенного примера.
- В сокращенном примере необходимо сохранять фактическую структуру исходного файла.
- Если поле является обязательным, это необходимо указать.
- Если поле допускает несколько типов значений или вариантов заполнения, это необходимо описать.
- Для наборов данных следует указывать, для какой части системы они используются.
- Необходимо отделять описание структуры данных от описания алгоритма их обработки.
- Если данные редактируются вручную, необходимо описать основные ограничения, которые нужно соблюдать при добавлении новых записей.
- Нельзя включать в примеры секретные данные, персональные данные или технические идентификаторы, публикация которых не требуется.
Для MenshikovAI отдельно следует описывать структуру набора интентов и структуру данных о городских локациях.
